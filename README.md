## GitHub Pages
1. Create a GitHub repository (example: `lumonere-site`).
2. Upload `index.html`, `style.css`, and the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL.

The page is static HTML/CSS/JS and does not require a server or database.
